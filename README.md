# RL Digital Asset Transfer Market Trading Agent

## Overview
This repository contains a Reinforcement Learning (RL) agent trained to execute profitable trades in a digital asset transfer market. Utilizing a Deep Q-Network (DQN), the agent learns autonomous algorithmic trading strategies (buy, sell, hold) by observing historical financial price fluctuations.

## Dependencies
- `Python 3.10+`
- `torch` (PyTorch)
- `gymnasium`
- `numpy`
- `yfinance`
